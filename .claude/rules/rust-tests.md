# Rust 测试规则

- 测试应验证可观察契约、边界条件和回归原因，避免仅复述实现细节。
- 需要临时文件的测试使用隔离目录；不要依赖仓库内已有构建产物、执行顺序或本机特定路径。
- 改动持久化格式、分词、召回、过滤、并发或跨平台行为时，优先扩展相邻的专项回归测试，而不是新建重复的通用测试。
- 需耗时运行的门禁测试可以沿用现有 `#[ignore]` 与 CI 入口，但普通单元/集成测试必须保持默认可运行。
