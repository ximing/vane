# M2-09 SQ8 向量量化

## 1. 目标
f32→SQ8 标量量化编解码 + 距离计算适配，内存降 4 倍（10万×384 全加载 <200MB，SPEC §13.1）。feature 可选（`sq8`），挂在 M2-07 懒加载的 vectors 访问点上，不改 `vectors()->&[f32]` 签名。

SPEC 节号：§13.1（SQ8 后 <200MB）、REQUIREMENTS §2（SQ8 Should have）、§3.3（M2 设计上限 100万）。

## 3. 接口契约
### Consumes from
- M2-07 `SegmentReader::vectors()`（懒加载访问点，SQ8 量化层挂在同一路径——首次 `sq8_vectors()` 触发从 `vectors()` 编码）。
- M0 `vane_core::vector::brute_search`、M1 `HnswReader::search`。

### Produces for
```rust
// crates/vane-core/src/vector/sq8.rs
pub fn encode_sq8(vectors: &[f32], dim: u32) -> Vec<u8>;       // 每维 1 字节，min/max + 256 级量化
pub fn decode_sq8(sq8: &[u8], dim: u32) -> Vec<f32>;
// 距离函数补 metric 参数（reviewer A-I3/B-I2）：覆盖 cosine/L2/dot 三种 metric
pub fn sq8_distance(sq8_a: &[u8], sq8_b: &[u8], dim: u32, metric: Metric) -> f32;  // 近似距离（不解码，快速）
pub fn sq8_query_distance(sq8_vectors: &[u8], query: &[f32], dim: u32, metric: Metric, topk: usize, filter: Option<&RoaringBitmap>, docid_base: u64) -> Vec<ScoredDoc>;
// sq8_query_distance 混合距离说明（reviewer B-M5）：query 是 f32，sq8_vectors 是 u8。
//   实现方式：先用 sq8_vectors 的 min/max（编码时记录，或每段 encode_sq8 时返回 Sq8Bundle{data,min,max}）
//   把 query 量化为 SQ8（同维度 min/max + 256 级），再调 sq8_distance(sq8_q, sq8_vec, dim, metric)。
//   避免每向量解码回 f32 的开销；query 量化一次复用于全段。

// SegmentReader 扩展（不改 vectors() 签名）：
impl SegmentReader {
    #[cfg(feature="sq8")]
    pub fn sq8_vectors(&self) -> Option<&[u8]>;  // 懒加载：首次调用从 vectors() 编码
}

// brute_search 扩展（不改原签名；与 brute_search 对齐补 metric + docid_base）：
#[cfg(feature="sq8")]
pub fn brute_search_sq8(sq8: &[u8], dim: u32, query: &[f32], metric: Metric, topk: usize, filter: Option<&roaring::RoaringBitmap>, docid_base: u64) -> Vec<ScoredDoc>;
```
下游：M2-10（100万规模依赖 SQ8 降内存）。

## 4. TDD 测试清单
1. **encode/decode roundtrip 误差**：`encode_sq8` → `decode_sq8`，每维误差 < `1/(256-1) * (max-min)`（SQ8 量化精度）。
2. **encode 内存缩减**：10万×384 f32 = 154MB → SQ8 = 38MB（4 倍降）。
3. **sq8_distance vs f32 distance（三 metric 覆盖）**：同向量对，`sq8_distance(.., metric)` 与 f32 精确距离误差 <1e-3，**分别覆盖 cosine / L2 / dot 三种 metric**（reviewer B-I2：原计划仅测 cosine，L2/dot 适配无测试）。
4. **brute_search_sq8 召回**：相对 f32 `brute_search` 基线，topK=10 recall@10 ≥0.95（SQ8 近似距离不显著影响召回，SPEC §13.2-1 口径）。
5. **sq8_vectors 懒加载**：open 后 `sq8_vectors()` None（未触发）；首次调用触发编码，返回 `Some(&[u8])`；多次调用幂等。
6. **sq8_vectors 依赖 vectors**：`sq8_vectors()` 内部调 `self.vectors()`（触发 f32 加载 → 编码 SQ8）。
7. **暴力回退路径用 sq8**（feature=sq8）：低选择率暴力回退走 `brute_search_sq8`，内存仅 SQ8 + 少量 f32（query）；结果 recall ≥0.95。
8. **HNSW 路径不改**（首选方案）：`HnswReader::search` 仍用 `vectors()` f32，签名不变（grep 验证 `hnsw/mod.rs:624` 签名未改）。
9. **feature 隔离**：`cargo test --no-default-features` 不编译 sq8 模块；`--features sq8` 编译。
10. **内存 <200MB**（10万×384，feature=sq8）：全加载（SQ8 vectors 38MB + HNSW 60MB + 倒排 + stored）<200MB（SPEC §13.1）。
11. **wasm32 编译**：`cargo check --target wasm32-unknown-unknown -p vane-core --features sq8` 通过（纯算术，无新依赖）。
12. **corpus 兼容**：SQ8 是内存缓存，不写段文件（vectors.bin 仍 f32）；corpus 兼容测试不破。
13. **I-5 守护**：`cfg(feature="sq8")` 允许在 segment/vector 编解码；无 `cfg(target)`。
