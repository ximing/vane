# BM25 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`。步骤用 checkbox，逐步 TDD（先红后绿），每步必须 `cargo test -p vane-core bm25` 通过后再勾选。

## Goal

实现 `vane_core::bm25` 模块：从分词后的 `Token` 流构建内存倒排索引，序列化为段内 `inverted.bin`（vbyte 编码 + Block-Max 跳块），并在读期提供 **Block-Max WAND top-k** 查询。查询返回 `Vec<ScoredDoc>`，供 `07-api-core` 的 text / hybrid 模式消费。

M0 规模承诺：10 万文档优化目标、50 万文档不塌（SPEC §3.3）。倒排全量加载进内存（M0 可接受；M1+ 视情况改 mmap/页缓存）。

## Architecture

```
写路径：
  Token[] ──> InvertedIndexBuilder::add_document
                  │ 累积 term -> [(docid, tf)]，记录 field_length
                  ▼
             InvertedIndexBuilder::build
                  │ term 字典序排序，posting 按 docid 升序
                  ▼
             InvertedData { doc_count, avgdl, field_lengths, terms }
                  │
                  ▼
             write_inverted(vfs, segment_dir, &data)
                  │ 每 128 doc 切跳块，块头写 max_score（BM25 上界）
                  │ posting 用 vbyte(docid_delta, tf)
                  ▼
             <segment_dir>/inverted.bin

读路径：
  InvertedIndexReader::open(vfs, segment_dir)
      │ 读 magic/version 校验 → 全量加载词典 + posting 块 + field_lengths
      ▼
  search(query_tokens, topk, filter)
      │ query term 去重 → 各 term 取 block 链 + IDF
      │ Block-Max WAND：按 block max_score 累加上界，剪枝 topK 堆
      │ filter（tombstone/pre-filter）位图过滤 docid
      ▼
  Vec<ScoredDoc>（按 score 降序，长度 ≤ topk）
```

关键设计决策：
1. **field_lengths 存 inverted.bin 头部**（不存 posting 内）。SPEC §6.3 规定 posting 是 `(docid_delta, tf)`，dl 是文档级属性，单独存更紧凑。M0 单 text 字段；多字段场景留待 M1（格式版本预留）。
2. **docid 存储为 delta**（相对前一 posting 的 docid），vbyte 编码紧凑；reader 累加还原绝对 docid。`inverted.bin` 头部记 `docid_base`，使 reader 自包含（不依赖 `SegmentReader`）。
3. **block max_score = block 内真实 BM25 分的最大值**（写入时 avgdl / N / IDF 全已知），非保守极限上界——剪枝更紧。
4. **WAND 简化为 Block-Max 候选驱动**：每轮取所有 term 当前指针的最小 docid 为候选，上界 = Σ 各 term 当前 block 的 max_score；上界 < 堆顶最小分则整体跳过候选 docid。M0 不实现完整 WAND 的 pivot 排序指针树（10 万规模够用，M1 再优化）。
5. **词典块用有序数组二分**（SPEC §6.3 允许；FST 留 M1）。

```rust
/// vbyte 变长编码（LEB128 风格，低 7 bit 先行，高位 1 = 还有后续字节）。
/// u32 最多 5 字节。
pub(crate) fn vbyte_encode(mut val: u32, out: &mut Vec<u8>) {
    loop {
        let b = (val & 0x7F) as u8;
        val >>= 7;
        if val == 0 {
            out.push(b);
            break;
        } else {
            out.push(b | 0x80);
        }
    }
}

/// 从 buf 起始位置解码一个 u32。返回 (值, 消费字节数)；截断返回 None。
pub(crate) fn vbyte_decode(buf: &[u8]) -> Option<(u32, usize)> {
    let mut val: u32 = 0;
    let mut shift: u32 = 0;
    for (i, &b) in buf.iter().enumerate() {
        val = val.checked_add(((b & 0x7F) as u32).checked_shl(shift)?)?;
        if b & 0x80 == 0 {
            return Some((val, i + 1));
        }
        shift += 7;
        if shift >= 35 {
            return None; // u32 溢出保护
        }
    }
    None
}
```

**Step 2.2 — 实现 add_document + build**

```rust
impl InvertedIndexBuilder {
    pub fn new(doc_count_hint: usize) -> Self {
        Self {
            doc_count_hint,
            doc_count: 0,
            total_field_length: 0,
            docid_base: 0,
            docid_base_set: false,
            field_lengths: Vec::with_capacity(doc_count_hint),
            terms: HashMap::new(),
        }
    }

    pub fn add_document(&mut self, docid: u64, tokens: &[Token], field_length: u32) {
        if !self.docid_base_set {
            self.docid_base = docid;
            self.docid_base_set = true;
        }
        self.doc_count += 1;
        self.total_field_length += field_length as u64;
        self.field_lengths.push(field_length);

        // 同一文档内同 term 累积 tf
        for t in tokens {
            let entry = self.terms.entry(t.text.clone()).or_default();
            *entry.entry(docid).or_insert(0) += 1;
        }
    }

    pub fn build(self) -> InvertedData {
        let avg_field_length = if self.doc_count == 0 {
            0.0
        } else {
            self.total_field_length as f32 / self.doc_count as f32
        };

        let mut terms: BTreeMap<String, TermPostings> = BTreeMap::new();
        for (term, doc_tf) in self.terms {
            let mut postings: Vec<Posting> = doc_tf
                .into_iter()
                .map(|(docid, tf)| Posting { docid, tf })
                .collect();
            postings.sort_by_key(|p| p.docid);
            let doc_freq = postings.len() as u32;
            terms.insert(term, TermPostings { doc_freq, postings });
        }

        InvertedData {
            docid_base: self.docid_base,
            doc_count: self.doc_count,
            avg_field_length,
            field_lengths: self.field_lengths,
            terms,
        }
    }
}
```

### Task 3：write_inverted（写 inverted.bin）

**Files:** `crates/vane-core/src/bm25.rs`

**Interfaces:**
- Consumes from 00/01: `Vfs`, `MAGIC`, `FORMAT_VERSION`, `BM25_K1`, `BM25_B`, `VaneError`, `Result`
- Produces: `pub fn write_inverted(vfs: &dyn Vfs, segment_dir: &str, data: &InvertedData) -> Result<()>`

**文件格式（inverted.bin）：**
```
magic(4, b"VANE") | format_version(4, u32 LE =1)
| docid_base(u64 LE) | num_docs(u32 LE) | avg_field_length(f32 LE)
| field_lengths: [u32 LE; num_docs]
| num_terms(u32 LE)
| 对每个 term（字典序）:
    term_len(u16 LE) | term_bytes(term_len)
    doc_freq(u32 LE) | num_blocks(u32 LE)
    对每个 block:
      max_score(f32 LE) | block_doc_count(u8) | vbyte(docid_delta, tf) × block_doc_count
```

block 切分：每 128 doc 一块（最后一块可不足）。`docid_delta` = 当前 posting docid - 前一 posting docid（块内首条 = 该 posting docid - 块前最后 docid；整个 term 链首条 delta = first_docid - 0，即 first_docid 绝对值，因为 docid 单调递增且 delta 累加从 0 起）。

> 注：`block_doc_count(u8)` 非末块恒 128，保留为自描述（读取时无需外部常量），无害。

**Step 3.2 — 实现 write_inverted + 块切分 + max_score**

```rust
const BLOCK_SIZE: usize = 128;

/// BM25 单 term 对单文档的分（SPEC §6.3 冻结公式）。
/// IDF = ln((N - df + 0.5)/(df + 0.5) + 1)
/// score = IDF * (tf*(k1+1)) / (tf + k1*(1 - b + b*dl/avgdl))
fn bm25_term_score(tf: u32, dl: u32, df: u32, n: u64, avgdl: f32) -> f32 {
    if avgdl <= 0.0 || n == 0 {
        return 0.0;
    }
    let idf = (((n as f64 - df as f64 + 0.5) / (df as f64 + 0.5) + 1.0).ln()) as f32;
    let tf_f = tf as f32;
    let dl_f = dl as f32;
    let denom = tf_f + BM25_K1 * (1.0 - BM25_B + BM25_B * (dl_f / avgdl));
    idf * (tf_f * (BM25_K1 + 1.0)) / denom
}

/// 计算 block 内 max_score：遍历 block 内文档取真实 BM25 分最大值。
fn block_max_score(
    postings: &[Posting],
    block_start: usize,
    block_len: usize,
    df: u32,
    n: u64,
    avgdl: f32,
    field_lengths: &[u32],
    docid_base: u64,
) -> f32 {
    let mut max = 0.0f32;
    for i in 0..block_len {
        let p = &postings[block_start + i];
        let local = (p.docid - docid_base) as usize;
        let dl = *field_lengths.get(local).unwrap_or(&0);
        let s = bm25_term_score(p.tf, dl, df, n, avgdl);
        if s > max {
            max = s;
        }
    }
    max
}

pub fn write_inverted(vfs: &dyn Vfs, segment_dir: &str, data: &InvertedData) -> Result<()> {
    let path = format!("{}/inverted.bin", segment_dir);
    vfs.create(&path)?;

    let mut buf: Vec<u8> = Vec::with_capacity(4096);
    // 头部
    buf.extend_from_slice(MAGIC);
    buf.extend_from_slice(&FORMAT_VERSION.to_le_bytes());
    buf.extend_from_slice(&data.docid_base.to_le_bytes());
    buf.extend_from_slice(&(data.doc_count as u32).to_le_bytes());
    buf.extend_from_slice(&data.avg_field_length.to_le_bytes());
    for &fl in &data.field_lengths {
        buf.extend_from_slice(&fl.to_le_bytes());
    }
    // 词典
    buf.extend_from_slice(&(data.terms.len() as u32).to_le_bytes());
    for (term, tp) in &data.terms {
        let term_bytes = term.as_bytes();
        let term_len = u16::try_from(term_bytes.len())
            .map_err(|_| VaneError::InvalidArg("term too long (>65535 bytes)".into()))?;
        buf.extend_from_slice(&term_len.to_le_bytes());
        buf.extend_from_slice(term_bytes);
        buf.extend_from_slice(&tp.doc_freq.to_le_bytes());

        // 切块
        let total = tp.postings.len();
        let num_blocks = total.div_ceil(BLOCK_SIZE) as u32;
        // 空 postings（doc_freq=0）→ num_blocks=0
        let num_blocks = if total == 0 { 0 } else { num_blocks };
        buf.extend_from_slice(&num_blocks.to_le_bytes());

        let mut prev_docid: u64 = 0;
        let mut idx = 0;
        while idx < total {
            let block_len = BLOCK_SIZE.min(total - idx);
            let max_score = block_max_score(
                &tp.postings, idx, block_len,
                tp.doc_freq, data.doc_count, data.avg_field_length,
                &data.field_lengths, data.docid_base,
            );
            buf.extend_from_slice(&max_score.to_le_bytes());
            buf.push(block_len as u8);
            for j in 0..block_len {
                let p = &tp.postings[idx + j];
                let delta = (p.docid - prev_docid) as u32;
                vbyte_encode(delta, &mut buf);
                vbyte_encode(p.tf, &mut buf);
                prev_docid = p.docid;
            }
            idx += block_len;
        }
    }

    vfs.write_at(&path, &buf, 0)?;
    vfs.sync(&path)?;
    Ok(())
}
```

> 注：`div_ceil` 在 stable Rust 1.73+ 提供（`usize::div_ceil`）。若工具链低于 1.73，替换为 `(total + BLOCK_SIZE - 1) / BLOCK_SIZE`。workspace MSRV 在 00-workspace 设定，本计划按 `div_ceil` 写，失败时回退。

**Step 4.2 — 实现 InvertedIndexReader + open**

```rust
use std::sync::Arc;

/// 加载到内存的 term 倒排（词典 + 块）。
pub struct TermEntry {
    pub doc_freq: u32,
    pub idf: f32,
    /// 块数组：每块 max_score + 块内 posting（已解 vbyte，绝对 docid 还原）
    pub blocks: Vec<Block>,
}

pub struct Block {
    pub max_score: f32,
    pub postings: Vec<Posting>, // 绝对 docid 升序
}

pub struct InvertedIndexReader {
    vfs: Arc<dyn Vfs>,
    segment_dir: String,
    docid_base: u64,
    doc_count: u64,
    avg_field_length: f32,
    field_lengths: Vec<u32>,
    /// 词典有序数组（按 term 字节序），二分查找
    terms: Vec<(String, TermEntry)>,
}

impl InvertedIndexReader {
    pub fn open(vfs: &std::sync::Arc<dyn Vfs>, segment_dir: &str) -> Result<Self> {
        let path = format!("{}/inverted.bin", segment_dir);

        // 先读头部确定大小，再全量读。M0 简化：读一个足够大的缓冲。
        // MemoryVfs 可一次读全部；StdFsVfs 需分次。这里采用：先读 4KB 探测，
        // 若不够再续读。为简化 M0，先读 header(8) + meta(8+4+4) = 24 字节定长。
        let mut header = [0u8; 8];
        let n = vfs.read_at(&path, &mut header, 0)?;
        if n < 8 {
            return Err(VaneError::Corrupt(format!("inverted.bin truncated header: {}", n)));
        }
        if &header[0..4] != MAGIC {
            return Err(VaneError::Corrupt("inverted.bin bad magic".into()));
        }
        let version = u32::from_le_bytes(header[4..8].try_into().unwrap());
        if version != FORMAT_VERSION {
            return Err(VaneError::Version(format!(
                "inverted.bin version {} != supported {}", version, FORMAT_VERSION
            )));
        }

        // 读取剩余全部：先读 meta 头（docid_base+num_docs+avgdl = 8+4+4=16），
        // 再读 field_lengths，再读词典。实现策略：一次性把整个文件读进 Vec<u8>。
        // 文件大小未知 → 探测式读取：尝试读一个大缓冲，按实际返回字节裁剪。
        // M0 简化：循环 read_at 增量读取直到返回 0。
        let mut blob: Vec<u8> = Vec::new();
        let mut offset: u64 = 8;
        let chunk = 64 * 1024;
        loop {
            let mut tmp = vec![0u8; chunk];
            let rn = vfs.read_at(&path, &mut tmp, offset)?;
            if rn == 0 {
                break;
            }
            blob.extend_from_slice(&tmp[..rn]);
            offset += rn as u64;
            if rn < chunk {
                break;
            }
        }
        // blob 现在是 [8..end)

        let mut cur = 0usize;

        let docid_base = read_u64_le(&blob, &mut cur)?;
        let num_docs = read_u32_le(&blob, &mut cur)?;
        let avg_field_length = read_f32_le(&blob, &mut cur)?;

        let mut field_lengths = Vec::with_capacity(num_docs as usize);
        for _ in 0..num_docs {
            field_lengths.push(read_u32_le(&blob, &mut cur)?);
        }

        let num_terms = read_u32_le(&blob, &mut cur)?;
        let mut terms: Vec<(String, TermEntry)> = Vec::with_capacity(num_terms as usize);

        for _ in 0..num_terms {
            // term_len u16
            if cur + 2 > blob.len() {
                return Err(VaneError::Corrupt("inverted.bin truncated term_len".into()));
            }
            let term_len = u16::from_le_bytes(blob[cur..cur+2].try_into().unwrap()) as usize;
            cur += 2;
            if cur + term_len > blob.len() {
                return Err(VaneError::Corrupt("inverted.bin truncated term_bytes".into()));
            }
            let term = String::from_utf8(blob[cur..cur+term_len].to_vec())
                .map_err(|e| VaneError::Corrupt(format!("inverted.bin term utf8: {}", e)))?;
            cur += term_len;

            let doc_freq = read_u32_le(&blob, &mut cur)?;
            let num_blocks = read_u32_le(&blob, &mut cur)?;

            let idf = if num_docs == 0 || doc_freq == 0 {
                0.0
            } else {
                (((num_docs as f64 - doc_freq as f64 + 0.5) / (doc_freq as f64 + 0.5) + 1.0).ln()) as f32
            };

            let mut blocks: Vec<Block> = Vec::with_capacity(num_blocks as usize);
            let mut prev_docid: u64 = 0;
            for _ in 0..num_blocks {
                let max_score = read_f32_le(&blob, &mut cur)?;
                if cur + 1 > blob.len() {
                    return Err(VaneError::Corrupt("inverted.bin truncated block_doc_count".into()));
                }
                let block_doc_count = blob[cur] as usize;
                cur += 1;
                let mut postings: Vec<Posting> = Vec::with_capacity(block_doc_count);
                for _ in 0..block_doc_count {
                    let (delta, dn) = vbyte_decode(&blob[cur..])
                        .ok_or_else(|| VaneError::Corrupt("inverted.bin vbyte delta".into()))?;
                    cur += dn;
                    let (tf, tn) = vbyte_decode(&blob[cur..])
                        .ok_or_else(|| VaneError::Corrupt("inverted.bin vbyte tf".into()))?;
                    cur += tn;
                    prev_docid = prev_docid.checked_add(delta as u64)
                        .ok_or_else(|| VaneError::Corrupt("inverted.bin docid overflow".into()))?;
                    postings.push(Posting { docid: prev_docid, tf });
                }
                blocks.push(Block { max_score, postings });
            }
            terms.push((term, TermEntry { doc_freq, idf, blocks }));
        }

        Ok(Self {
            vfs: vfs.clone(),
            segment_dir: segment_dir.to_string(),
            docid_base,
            doc_count: num_docs as u64,
            avg_field_length,
            field_lengths,
            terms,
        })
    }

    pub fn doc_count(&self) -> u64 {
        self.doc_count
    }

    pub fn avg_field_length(&self) -> f32 {
        self.avg_field_length
    }

    /// 查找 term（二分，有序数组）。
    fn lookup(&self, term: &str) -> Option<&TermEntry> {
        self.terms
            .binary_search_by(|(t, _)| t.as_str().cmp(term))
            .ok()
            .map(|i| &self.terms[i].1)
    }

    fn field_length_of(&self, docid: u64) -> u32 {
        let local = docid.saturating_sub(self.docid_base) as usize;
        self.field_lengths.get(local).copied().unwrap_or(0)
    }
}

// TermEntry / Block 已在上方定义
```

`open` 内调用的 `read_u32_le` / `read_u64_le` / `read_f32_le` 为模块级自由函数（S7 裁决，主实现非 fallback），定义如下：

```rust
fn read_u32_le(b: &[u8], off: &mut usize) -> Result<u32> {
    if *off + 4 > b.len() {
        return Err(VaneError::Corrupt("inverted.bin truncated u32".into()));
    }
    let v = u32::from_le_bytes(b[*off..*off + 4].try_into().unwrap());
    *off += 4;
    Ok(v)
}
fn read_u64_le(b: &[u8], off: &mut usize) -> Result<u64> {
    if *off + 8 > b.len() {
        return Err(VaneError::Corrupt("inverted.bin truncated u64".into()));
    }
    let v = u64::from_le_bytes(b[*off..*off + 8].try_into().unwrap());
    *off += 8;
    Ok(v)
}
fn read_f32_le(b: &[u8], off: &mut usize) -> Result<f32> {
    if *off + 4 > b.len() {
        return Err(VaneError::Corrupt("inverted.bin truncated f32".into()));
    }
    let v = f32::from_le_bytes(b[*off..*off + 4].try_into().unwrap());
    *off += 4;
    Ok(v)
}
```

### Task 5：Block-Max WAND search

**Files:** `crates/vane-core/src/bm25.rs`

**Interfaces:**
- Consumes: `Token`, `ScoredDoc`, `BM25_K1`, `BM25_B`, `roaring::RoaringBitmap`
- Produces: `InvertedIndexReader::search`

**算法（Block-Max WAND 简化版）：**

1. query_tokens 去重（按 text），每个 term `lookup` 取 `TermEntry`；缺失 term 跳过。
2. 每个 term 维护 `(block_idx, in_block_idx)` 指针，初始 (0,0)。
3. 循环：
   - 收集各 term 当前指针的 docid（若指针已到末尾，该 term 退出）。
   - 若全部退出，结束。
   - 候选 docid = 所有 term 当前 docid 的最小值。
   - 上界分 = Σ 各 term 当前 block 的 `max_score`（仅对当前 docid 所在 block）。
   - 若 topK 堆未满 或 上界 > 堆顶最小分：计算候选文档真实分（Σ 各 term 对该 docid 的真实 BM25 分，仅 term 当前 docid == 候选时计入），更新堆。filter 不匹配则跳过。
   - 若上界 ≤ 堆顶最小分 且堆满：跳过候选（推进所有 term 当前 docid ≤ 候选 的指针到 docid > 候选）。
   - 推进所有 term 当前 docid == 候选 的指针前进一格（in_block_idx++，若跨块则 block_idx++）。

```rust
    fn brute_baseline(
        reader: &InvertedIndexReader,
        query: &[Token],
        topk: usize,
        filter: Option<&RoaringBitmap>,
    ) -> Vec<ScoredDoc> {
        // 收集 query term（去重）
        let mut qterms: Vec<&str> = query.iter().map(|t| t.text.as_str()).collect();
        qterms.sort();
        qterms.dedup();

        let n = reader.doc_count();
        let avgdl = reader.avg_field_length();
        let mut scores: std::collections::HashMap<u64, f32> = std::collections::HashMap::new();
        for qt in &qterms {
            let te = match reader.lookup(qt) { Some(t) => t, None => continue };
            for blk in &te.blocks {
                for p in &blk.postings {
                    if let Some(f) = filter {
                        if !f.contains(p.docid) { continue; }
                    }
                    let dl = reader.field_length_of(p.docid);
                    let s = bm25_term_score(p.tf, dl, te.doc_freq, n, avgdl);
                    *scores.entry(p.docid).or_insert(0.0) += s;
                }
            }
        }
        let mut v: Vec<ScoredDoc> = scores
            .into_iter()
            .map(|(docid, score)| ScoredDoc { docid, score })
            .collect();
        v.sort_by(|a, b| b.score.partial_cmp(&a.score).unwrap_or(std::cmp::Ordering::Equal));
        v.truncate(topk);
        v
    }
```

**Step 5.2 — 实现 search**

```rust
use std::collections::BinaryHeap;
use std::cmp::Reverse;

impl InvertedIndexReader {
    pub fn search(
        &self,
        query_tokens: &[Token],
        topk: usize,
        filter: Option<&roaring::RoaringBitmap>,
    ) -> Vec<ScoredDoc> {
        if topk == 0 || query_tokens.is_empty() || self.doc_count == 0 {
            return Vec::new();
        }

        // query term 去重（保留首次出现）
        let mut seen: std::collections::HashSet<&str> = std::collections::HashSet::new();
        let mut qterms: Vec<&TermEntry> = Vec::new();
        for t in query_tokens {
            if seen.insert(t.text.as_str()) {
                if let Some(te) = self.lookup(&t.text) {
                    qterms.push(te);
                }
            }
        }
        if qterms.is_empty() {
            return Vec::new();
        }

        // 每个 term 的指针：(block_idx, in_block_idx)
        let mut cursors: Vec<(usize, usize)> = vec![(0, 0); qterms.len()];
        // 最小堆（Reverse 包裹做 min-heap），存 (score, docid)
        let mut heap: BinaryHeap<Reverse<(OrderedFloat, u64)>> = BinaryHeap::with_capacity(topk + 1);

        loop {
            // 收集各 term 当前 docid
            let mut current: Vec<Option<u64>> = Vec::with_capacity(qterms.len());
            let mut alive = false;
            for (i, te) in qterms.iter().enumerate() {
                let (bi, ii) = cursors[i];
                if bi < te.blocks.len() {
                    let blk = &te.blocks[bi];
                    if ii < blk.postings.len() {
                        current.push(Some(blk.postings[ii].docid));
                        alive = true;
                        continue;
                    }
                }
                current.push(None);
            }
            if !alive {
                break;
            }

            // 候选 = min docid
            let candidate = current.iter().copied()
                .filter_map(|x| x)
                .min()
                .unwrap();

            // 上界分 = Σ 各 term 当前 block 的 max_score（仅对当前 docid 所在 block）
            let mut upper = 0.0f32;
            for (i, te) in qterms.iter().enumerate() {
                let (bi, ii) = cursors[i];
                if bi < te.blocks.len() {
                    let blk = &te.blocks[bi];
                    if ii < blk.postings.len() && blk.postings[ii].docid == candidate {
                        upper += blk.max_score;
                    }
                }
            }

            // 剪枝判断
            let should_skip = heap.len() == topk
                && !heap.is_empty()
                && {
                    let Reverse((top_score, _)) = *heap.peek().unwrap();
                    upper <= top_score.0
                };

            if !should_skip {
                // filter 检查
                let pass = match filter {
                    None => true,
                    Some(f) => f.contains(candidate as u32),
                };
                if pass {
                    // 真实分
                    let mut score = 0.0f32;
                    for (i, te) in qterms.iter().enumerate() {
                        let (bi, ii) = cursors[i];
                        if bi < te.blocks.len() {
                            let blk = &te.blocks[bi];
                            if ii < blk.postings.len() && blk.postings[ii].docid == candidate {
                                let p = &blk.postings[ii];
                                let dl = self.field_length_of(p.docid);
                                score += bm25_term_score(
                                    p.tf, dl, te.doc_freq,
                                    self.doc_count, self.avg_field_length,
                                );
                            }
                        }
                    }
                    // 入堆
                    heap.push(Reverse((OrderedFloat(score), candidate)));
                    if heap.len() > topk {
                        heap.pop();
                    }
                }
            }

            // 推进所有 term 当前 docid == candidate 的指针
            for (i, te) in qterms.iter().enumerate() {
                let (bi, ii) = cursors[i];
                if bi < te.blocks.len() {
                    let blk = &te.blocks[bi];
                    if ii < blk.postings.len() && blk.postings[ii].docid == candidate {
                        let mut nbi = bi;
                        let mut nii = ii + 1;
                        if nii >= blk.postings.len() {
                            nbi += 1;
                            nii = 0;
                        }
                        cursors[i] = (nbi, nii);
                    }
                }
            }
        }

        // 输出：堆转 Vec，按 score 降序
        let mut out: Vec<ScoredDoc> = heap
            .into_iter()
            .map(|Reverse((OrderedFloat(score), docid))| ScoredDoc { docid, score })
            .collect();
        out.sort_by(|a, b| b.score.partial_cmp(&a.score).unwrap_or(std::cmp::Ordering::Equal));
        out
    }
}
```

> `OrderedFloat` 引入：为避免 f32 不实现 Ord 的问题，定义一个本地 wrapper：
```rust
#[derive(Debug, Clone, Copy, PartialEq)]
struct OrderedFloat(f32);
impl Eq for OrderedFloat {}
impl PartialOrd for OrderedFloat {
    fn partial_cmp(&self, other: &Self) -> Option<std::cmp::Ordering> { Some(self.cmp(other)) }
}
impl Ord for OrderedFloat {
    fn cmp(&self, other: &Self) -> std::cmp::Ordering {
        self.0.partial_cmp(&other.0).unwrap_or(std::cmp::Ordering::Equal)
    }
}
```
> 不引入 `ordered-float` crate（避免新依赖；自实现 8 行足够）。放在 `bm25.rs` 模块级。

运行 `cargo test -p vane-core bm25::search_tests` → 全绿。勾选。

> **剪枝正确性论证**：上界 `upper = Σ max_score(block_i)` 对候选 d 的真实分是合法上界（block 内任一文档对 term i 的分 ≤ block max_score）。当 `upper ≤ 堆顶最小分` 且堆满时，d 不可能进 topK，安全跳过。与暴力基线 100% 一致由 `search_matches_brute_large_topk` 与 `search_blockmax_pruning_correctness_large` 保证。

## 风险与备注

1. **`div_ceil` MSRV**：`usize::div_ceil` 需 Rust 1.73+。00-workspace 设定 MSRV 后，若低于 1.73，Task 3 Step 3.2 的 `total.div_ceil(BLOCK_SIZE)` 改 `(total + BLOCK_SIZE - 1) / BLOCK_SIZE`。
2. **MemoryVfs 隐式建目录**：`write_inverted` 仅调 `vfs.create(path)` + `write_at`，不显式 mkdir（Vfs trait 无 mkdir 原语）。依赖 01-vfs 的 `create` / `write_at` 隐式建中间路径。若 01-vfs 实现需显式建目录，需在 01 计划补 mkdir 语义或在 05 调整——M0 以 MemoryVfs 行为为准，StdFsVfs 在 01 计划里保证 `create` 隐式建父目录。
3. **全量加载内存**：M0 `InvertedIndexReader::open` 全量读 inverted.bin 进内存。10 万文档 × 平均 100 term/文档 × 8 字节/posting ≈ 80MB，在 M0 500MB 内存预算内（SPEC §13.1）。M1+ 改为按需读块 + PageCache。
4. **WAND 简化**：M0 实现为"候选驱动 + block-max 剪枝"，非完整 WAND 指针树。10 万规模查询延迟 < 50ms 可达（SPEC §13.1 text 模式未单列，参考 hybrid P99 < 150ms 暴力口径）。M1 若需优化升级为完整 WAND。
5. **`OrderedFloat` NaN 语义**：BM25 分不会产生 NaN（IDF 输入均为正，分母 > 0）。`Ord` 实现对 NaN 返回 Equal，不会 panic，但若未来出现 NaN 会破坏排序正确性——由 `bm25_term_score` 的 `avgdl <= 0` 守卫保证不产生 NaN。
6. **多 text 字段**：M0 单 text 字段（`add_document` 传单个 `field_length`）。多字段需 per-field 倒排，格式版本 2 预留。本计划不触及。
