# v0.1.1 修复报告：npm 包缺 index.js + version bump

> 2026-08-10。修复 v0.1.0 npm 包 `@vane-rs/node` 安装后 `require('@vane-rs/node')` 报 `Cannot find module './index.js'` 的发版产物硬伤，并 bump version 0.1.0 → 0.1.1 准备重发版。

## 根因

v0.1.0 npm 包 `@vane-rs/node` 安装后 `require('@vane-rs/node')` 报 `Cannot find module './index.js'`。`main.js` require `./index.js`（napi-rs 生成的平台切换 loader），但 `index.js` 被 `crates/vane-node/.gitignore` 忽略（napi build 生成，不入库）。`release.yml` build job 跑 `napi build` 生成 `index.js` 但 upload-artifact 只传 `.node`；release job checkout 后工作树无 `index.js`（gitignore），stage 步骤只 cp `.node` → npm publish 包缺 `index.js`。

## 改动 1：release.yml 修复 index.js stage

### build job upload-artifact（加 index.js）

```yaml
      - uses: actions/upload-artifact@v4
        with:
          name: vane-node-${{ matrix.node_platform }}
          path: |
            crates/vane-node/*.node
            crates/vane-node/index.js
```

4 平台 build job 都 `napi build` 生成相同 `index.js`，各 artifact 含 `.node` + `index.js`。

### release job stage step（加 index.js cp）

```yaml
      - name: Stage node .node + index.js into crates/vane-node/
        run: |
          cp artifacts/vane-node-*/*.node crates/vane-node/
          cp artifacts/vane-node-linux-x64-gnu/index.js crates/vane-node/
          ls -lh crates/vane-node/*.node crates/vane-node/index.js
```

`index.js` 4 平台相同，从 linux-x64-gnu artifact 取一份即可。stage 后 `crates/vane-node/` 含 `.node`×4 + `index.js`，`npm publish` 主包 `files` 字段已列出 `index.js`（package.json line 6），发布产物完整。

## 改动 2：bump version 0.1.0 → 0.1.1（三端同步）

npm 不允许 republish 同版本，需 patch 0.1.1。

| 文件 | 改动 |
|------|------|
| `Cargo.toml`（workspace） | `version = "0.1.0"` → `"0.1.1"` |
| `Cargo.lock` | 4 个 workspace crate（vane-core/ffi/node/wasm）`0.1.0` → `0.1.1`（`cargo update -p` 同步） |
| `crates/vane-node/package.json` | `"version": "0.1.1"` + 4 个 optionalDependencies `@vane-rs/node-*`: `"0.1.1"` |
| `.github/workflows/release.yml` | workflow_dispatch input description `'版本号（如 0.1.1）'` |
| `.github/workflows/install-matrix.yml` | workflow_dispatch input `default: '0.1.1'` |

### 版本继承说明

- `vane-core`、`vane-ffi`、`vane-node`、`vane-wasm` 的 Cargo.toml 均用 `version.workspace = true`，继承 workspace package version，无需单独改。
- `vane-dict-zh` 使用独立日期版本 `2026.8.0`（词典包，非 semver 跟随），不改。
- `crates/vane-node/napi.config.json` 不含 `packageVersion` 字段——napi-rs 默认从 `package.json` 读取 version，无需改动。
- Go `.a`（`libvane_ffi-<platform>.a`）与 WASM `.wasm` 文件名不含 version，无需改。
- `go.mod` module 路径不含 semver，不改。
- `docs/` 下 0.1.0 引用均为历史记录（M0/post-M2 计划文档描述 v0.1.0 发版过程），保留不动。
